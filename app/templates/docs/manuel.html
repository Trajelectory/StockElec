StockEleK
Gestionnaire de stock électronique pour makers. Catalogue tes composants, suis tes projets, localise physiquement chaque pièce avec des LEDs, génère tes bibliothèques KiCad.
Flask + SQLite Dark theme ESP32-S3 WS2812B HT16K33 KiCad LCSC / Mouser / DigiKey
👋
Présentation
01

StockEleK est une application web locale pour maker solo. Lance-la sur ton PC, accède-y depuis le navigateur, et gère l'intégralité de ton atelier électronique depuis un seul endroit.

Ce que tu peux faire
  • Cataloguer tous tes composants électroniques
  • Suivre les quantités en stock en temps réel
  • Localiser physiquement chaque composant (tiroir + position)
  • Allumer des LEDs pour trouver un composant en 2 secondes
  • Gérer tes projets maker avec BOM, notes, checklist
  • Générer des bibliothèques KiCad automatiquement
  • Imprimer des étiquettes QR code pour tes tiroirs
Architecture
  • Backend : Python Flask + SQLite
  • Frontend : HTML/CSS/JS, dark theme natif
  • Données : instance/stock.db — un fichier
  • Images : instance/images/
  • 100% hors ligne — pas de cloud
  • Accessible depuis tout appareil du réseau local
💡
Sauvegarde : toutes tes données sont dans instance/stock.db et instance/images/. Copie ces deux dossiers régulièrement — c'est tout ce dont tu as besoin pour migrer ou restaurer StockEleK. Un bouton Télécharger la sauvegarde est disponible dans Paramètres → Backup.

02

Premier lancement — que faire en premier ?
1

3

4
Commence à ajouter tes composants via Ajouter ou importe un CSV depuis /import

Ajouter un composant
05
Méthode 1 — Par référence LCSC (recommandée)

Saisis la référence LCSC (ex: C49678) et StockEleK récupère automatiquement description, catégorie, package, prix, image et datasheet.

1
Clique sur + Ajouter
2
Saisis la référence LCSC — un aperçu apparaît instantanément
3
Renseigne la quantité et l'emplacement physique (ex: B03)
4
Valide — le composant est créé avec toutes ses infos enrichies
Méthode 2 — Manuel

Pour les composants sans référence LCSC (pièces maison, mécaniques…). Remplis les champs manuellement, ajoute une photo si besoin.

Méthode 3 — Import CSV

Via /import. StockEleK propose un mapping interactif des colonnes et détecte les doublons (mise à jour plutôt que doublon si même référence LCSC).

💡
Si tu commandes sur LCSC, exporte ton panier en CSV et importe-le directement — les colonnes LCSC standard sont reconnues automatiquement.

Enrichissement automatique
06
🟣 LCSC (recommandé)
  • Gratuit, sans clé API
  • Description, catégorie, package, prix
  • Image du composant
  • Datasheet PDF
  • Symbole & footprint PNG (aperçu visuel)
🔵 Mouser / DigiKey
  • Nécessite une clé API (gratuite)
  • À configurer dans Paramètres
  • Description, prix, stock fournisseur
  • Image et datasheet

Enrichissement individuel : sur la fiche composant, bouton ✨ Enrichir. Se fait en arrière-plan.

Enrichissement en masse : dans Paramètres → LCSC & EasyEDA, bouton Enrichir tous — traite tous les composants sans image ou catégorie. Idéal après un import CSV massif.

⚠️
L'enrichissement en masse fait des requêtes réseau. Attends qu'un batch soit terminé avant d'en relancer un.

08

Les catégories sont renseignées automatiquement via l'enrichissement LCSC (format Famille / Sous-famille). La page /categories liste toutes les catégories avec le nombre de composants, et permet de renommer ou fusionner.

Alertes de stock
09

La page /alerts (icône 🔔 dans la navbar) liste tous les composants dont la quantité est inférieure ou égale au stock minimum. Ce seuil se configure par composant ou globalement dans les paramètres.

La page /reorder est une version avancée : références fournisseurs, prix et liens directs LCSC/Mouser/DigiKey, export CSV pour commander.

LEDs & Arduino
17

L'ESP32-S3 pilote des rubans WS2812B et expose une API REST. StockEleK y envoie les commandes d'allumage depuis le navigateur.

Architecture hardware
ComposantRôle
ESP32-S3 Wroom-1Cerveau — WiFi, API REST, gestion LEDs
Ruban 1 (GPIO 5)LEDs de position — une par case de tiroir (jusqu'à 500)
Ruban 2 (GPIO 18)LEDs de tiroir — une par lettre A-Z (26 LEDs)
HT16K33 (I2C)Afficheur 14 segments — affiche la case (ex: "A 16")
Couleurs LED par catégorie nouveau

Les LEDs s'allument dans une couleur automatique selon la catégorie du composant — orange pour les résistances, bleu pour les condensateurs, vert pour les transistors, etc. Les couleurs sont entièrement personnalisables dans Paramètres → ESP32 → Couleurs LED par catégorie avec des color pickers.

Paramètres firmware (gridfinity_leds_Arduino.ino)
ConstanteValeurDescription

NUM_LEDS500Nombre max de LEDs — ajuste à ta config réelle
DRAWER_PIN18GPIO ruban tiroirs
NUM_DRAWERS26Nombre de tiroirs
BRIGHTNESS255Luminosité 0-255
DEFAULT_SEC5Durée d'allumage par défaut
DISPLAY_SDA8GPIO I2C SDA (ESP32-S3)
DISPLAY_SCL9GPIO I2C SCL (ESP32-S3)
DISPLAY_SLEEP_SEC33Secondes avant veille de l'afficheur
Bibliothèques Arduino requises

⚠️
Alimentation : les WS2812B consomment jusqu'à 60mA par LED à pleine luminosité blanche. Prévois une alimentation 5V dédiée pour les rubans — ne passe jamais par le 5V de l'ESP32.
🖥️
Afficheur HT16K33
18

Afficheur 14 segments optionnel — si non branché, le firmware continue normalement.

Câblage (ESP32-S3 Wroom-1)
  • SDA → GPIO 8
  • SCL → GPIO 9
  • VCC → 3.3V
  • GND → GND
  • Adresse I2C : 0x70 (A0-A2 = GND)
Comportement
  • Composant trouvé → A 16
  • Test (/test) → TEST
  • Inactif 33s → -- clignotants
  • Démarrage → ---- 800ms puis éteint
  • Absent → simulation Serial Monitor

Intégration KiCad
20

StockEleK génère des fichiers KiCad (.kicad_sym, .kicad_mod, .step) pour tous tes composants LCSC via JLC2KiCadLib. Les fichiers sont organisés par catégorie dans instance/kicad/.

Prérequis

JLC2KiCadLib doit être installé sur ta machine :

1
pip install JLC2KiCadLib dans ton environnement Python
2
Vérifie que la commande JLC2KiCadLib est accessible dans le PATH
Structure générée

Les fichiers sont organisés dans instance/kicad/ selon la catégorie JLCPCB :

DossierContenu
Resistors/Tous les fichiers des résistances
Resistors/0805W8F_C149504/Dossier par composant : PartNumber_LCSC
Resistors/0805W8F_C149504/*.kicad_symSymbole KiCad individuel
Resistors/0805W8F_C149504/*.kicad_modFootprint KiCad
Resistors/0805W8F_C149504/*.stepModèle 3D
Resistors/Resistors.kicad_symLibrairie fusionnée (après fusion)
Générer les fichiers
1
Paramètres → KiCad Library
2
Choisis le délai entre requêtes — 2s recommandé pour éviter le rate limit
3
Clique ⚙️ Générer / Mettre à jour — le job tourne en arrière-plan avec une barre de progression
4
Les composants déjà générés sont ignorés — tu peux relancer sans risque
ℹ️
Seuls les composants avec une référence LCSC valide sont traités. Les composants sans données KiCad disponibles sont skippés silencieusement.
Fusionner les symboles par catégorie

Une fois la génération terminée, clique 📚 Fusionner les symboles pour créer un fichier .kicad_sym par catégorie regroupant tous les symboles. Exemple : Resistors/Resistors.kicad_sym contient tous les symboles de résistances.

💡
C'est la façon native de KiCad — tu importes une seule librairie par catégorie plutôt qu'un fichier par composant.
Importer dans KiCad
1
Clique 📥 Télécharger le ZIP — décompresse dans un dossier permanent sur ta machine
2
Symboles — KiCad → Préférences → Gérer les bibliothèques de symboles → ajoute chaque Catégorie/Catégorie.kicad_sym
3
Footprints — KiCad → Préférences → Gérer les bibliothèques d'empreintes → ajoute les dossiers contenant les .kicad_mod
4
Modèles 3D — les fichiers .step sont dans les mêmes dossiers que les footprints
Badges de statut sur la fiche composant

Chaque fiche composant affiche des badges indiquant si les fichiers KiCad ont été générés :

● sym ● fp ● 3D

Vert = généré, gris = non généré. Les badges n'apparaissent que pour les composants avec une référence LCSC.

API REST de l'ESP32
21

Le firmware ESP32 expose une API REST sur le port 80. Toutes les routes sauf /ping nécessitent le header X-Token: [token].

POST/ledsAllumer des LEDs
Body JSON : {"leds": [0,1,2], "drawer": 0, "cell": "A01", "color": "#00CC44", "duration": 5}
POST/offTout éteindre
Pas de body. Éteint rubans 1 et 2, afficheur, vide la file d'attente.
GET/statusÉtat complet
Retourne : active, leds_on, cell, remaining_sec, display_ready, display_sleeping, uptime_sec
GET/pingVérification (sans token)
Retourne : ok, leds, drawers, display, rssi, uptime
POST/testChenillard de test
Body optionnel : {"offset": 0, "count": 500, "delay_ms": 80, "color": "green"}
